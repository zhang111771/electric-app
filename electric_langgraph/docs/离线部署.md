# 电网智能体 · 完全离线部署手册

适用场景：目标机器**彻底断网**。思路是——在**一台有网的打包机**上把一切准备好，
打成一个部署包，U 盘 / 内网拷贝到部署机即可。

## 一、部署包构成

```
deploy-bundle/
├── app/                       # 本项目全部代码（含 bundle/、scripts/）
│   ├── bundle/pgvector/       # pgvector 二进制（vector.dll + vector.control + vector--*.sql）
│   ├── scripts/install_pgvector.ps1
│   └── ...
├── wheels/                    # Python 依赖离线包（pip download 生成）
├── bge-m3.gguf                # Ollama embedding 模型（约 600MB）
└── 部署步骤.md                # 本手册
```

## 二、打包机（有网）准备

### 1. 准备 pgvector 二进制
```powershell
# 用 Stack Builder 装一次（选 PostgreSQL 16 实例 → 勾选 pgvector）
D:\postgres\bin\stackbuilder.exe
# 装好后把文件拷进 bundle/pgvector/
Copy-Item D:\postgres\lib\vector.dll bundle\pgvector\
Copy-Item D:\postgres\share\extension\vector.control, D:\postgres\share\extension\vector--*.sql bundle\pgvector\
```

### 2. 导出 Ollama embedding 模型（bge-m3）
```bash
# 先拉取（约 600MB，只需一次）
ollama pull bge-m3
# 找到 GGUF 文件位置
ollama show bge-m3 --modelfile   # 看 FROM /path/to/xxx.gguf
# 把该 .gguf 拷到部署包（保留文件名）
cp <模型文件路径> deploy-bundle/bge-m3.gguf
```

### 3. 导出 Python 依赖离线包
```bash
cd app
pip download -r requirements.txt -d ../wheels
```

## 三、部署机（断网）步骤

### 1. 装 PostgreSQL + pgvector
```powershell
# 安装 PostgreSQL 16（标准安装包，装到 D:\postgres，端口 5432，记好 postgres 密码）
# 然后离线安装 pgvector：
cd app
powershell -ExecutionPolicy Bypass -File scripts\install_pgvector.ps1 -PgPassword 你的密码
```

### 2. 离线导入 Ollama bge-m3
```bash
# 安装 Ollama（安装包需提前下载好），启动后在部署包目录执行：
ollama create bge-m3 -f - <<'EOF'
FROM ./bge-m3.gguf
EOF
# 验证：
ollama list        # 能看到 bge-m3
curl http://localhost:11434/v1/embeddings -d '{"model":"bge-m3","input":"测试"}' 
```
> 注意：离线导入后模型名必须叫 `bge-m3`（与 `config.py` 的 `EMBEDDING_MODEL` 一致）。
> 也可把 `bge-m3.gguf` 放进 Ollama 模型目录直接使用。

### 3. 安装 Python 依赖 + 初始化数据库
```bash
conda create -n langgraph python=3.11 -y
conda activate langgraph
pip install --no-index --find-links ../wheels -r requirements.txt

# 配置 .env（见 .env.example；LLM_API_KEY 用你们的内网网关 key）
cp .env.example .env

# 生成模拟业务数据（台账/负荷/告警）→ 自动建库
python data/generate_data.py

# 知识库入库（bge-m3 编码 → 写入 pgvector 表）
python data/seed_knowledge.py
```

### 4. 启动
```bash
bash scripts/run_local.sh
# 浏览器打开 http://127.0.0.1:8000
```

## 四、验证

```sql
-- 1) pgvector 扩展可用
psql -U postgres -d electric_power -c "SELECT vector_dims('[1,2,3]');"   -- 应返回 3

-- 2) 知识库已入库
psql -U postgres -d electric_power -c "SELECT count(*) FROM kb_chunks;"   -- 应 > 0
```

然后在网页提问"变压器过负荷运行有什么规定？"，回答应能引用资料库内容。

## 五、可选：升级到 PostgreSQL 18

本手册默认 PG16。若要用新装的 PG18，需：装 PG18 → 安装 pgvector-for-PG18 →
`pg_dump` 导出 electric_power → 导入 PG18 → 更新 `.env` 的 `POSTGRES_URI`。
pgvector 0.8.x 同时支持 PG16/PG18，二进制版本必须与 PG 主版本匹配。
